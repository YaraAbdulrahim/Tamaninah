# Verified source — `/source`

**Authority:** `docs/PRD.md` §27 · Flow: `UX-STRUCTURE.md` §9

The source is **not** a small link at the bottom. It is a core part of the experience, reachable from every story beat.

---

## Climate

Daylight. Documentary — not gold-ceremonial, not a footnote.

## Rule

**Story → Claim → Source.** Every sensitive piece of information has an origin that can be returned to.

## Shows

- Source name
- Source type (Qur'an, ḥadīth collection, sīrah work, …)
- Reference
- Original text where needed
- Translation where needed
- Context of the source
- **What was quoted verbatim**
- **What was summarised**
- Any limits or uncertainty, in plain language
- What the AI did: retrieved and organised, not authored

## Treatment

Typographic citation, hairline, radius 12px so it reads as documentary. Qur'an in Amiri Quran when quoted, and paraphrase visually distinct from quotation. `SealCheck` **with** the words "مصدر موثّق / Verified source" — never an icon alone, never a decorative badge.

## Then

Back into the conversation, on to a practical next step, or deeper into related knowledge.
